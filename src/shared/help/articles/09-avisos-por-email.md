# Avisos por e-mail
Quais e-mails o Lumen Deal envia e como escolher os seus.

| Quando | Quem recebe |
|---|---|
| Cliente abre a proposta pela primeira vez | Equipe (quem estiver com o aviso ligado) |
| Cliente aceita, pede ajuste ou recusa | Equipe (quem estiver com o aviso ligado) |
| Cliente aceita | O próprio cliente, com o resumo e o código de verificação |
| Convite de equipe | A pessoa convidada |

- Cada pessoa escolhe os próprios avisos em **Equipe → Seus avisos por e-mail**.
- Responder o aviso de resposta escreve direto para o cliente; quando o cliente responde a confirmação, a mensagem vai para o e-mail da empresa.
- Se o envio falhar, o sistema tenta de novo automaticamente.
